# Field Notes

Personal journaling tool. Private.

## Deploy your own

Anyone can run their own copy in a few clicks — no coding needed.

[![Fork and deploy](https://img.shields.io/badge/Deploy_to_GitHub_Pages-Fork_%26_run-0a0a0a?style=for-the-badge&logo=github)](../../fork)

See [SETUP.md](SETUP.md) for the step-by-step guide.

## What it is

A static, offline-first browser app. All data stays on the device. Optional encrypted backup to a repo of your choosing.

## Develop locally

```
npm install
npm run dev
```

To build a production bundle:
```
npm run build
```

To run the test suite:
```
npm test
```
